# Compose services

The Docker Compose services of each environment. The base `docker-compose.yaml` **is prod**; staging and lab stack overlays on top of it with extra `-f` flags, and the VPN overlays move SearXNG into a gluetun network namespace. Pick an environment to see the merged result, or a single file to see exactly what it declares.

Generated by `scripts/gen/compose.ts` from every `docker-compose*.yaml` in this worktree (`bun run gen` in `docs-site/`). Environment values of secret-named keys are redacted; values that come from the host-local `.env` show as "(host env)".

::: warning This worktree's copy
Each environment deploys from **its own worktree** (prod = `ask-prod`, staging = `ask`, lab = `ask-flow`). The overlays shown here are this branch's copies and can drift from what another environment actually runs. See [Environments](/operations/environments).
:::
